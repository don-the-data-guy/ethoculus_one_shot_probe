# Ethoculus Experiments

Each experiment should define, before execution:

- the research question;
- hypothesis;
- control condition;
- treatment conditions;
- independent variable;
- dependent variable;
- model and version;
- number of trials;
- evaluation method;
- evidence classification;
- limitations;
- and a proposed falsification test.

The purpose is to preserve the distinction between observation,
inference, and claims about internal mechanism.

Agent experiments (ETH-003 onward) are defined as manifests in `manifests/`.
Each manifest carries the same preregistration fields as the YAML files here,
plus the tools, cases, conditions, and scoring rules the runner executes.
